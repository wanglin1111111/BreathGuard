# Wi-Fi CSI 感知链路验证：测试总报告

> **文档说明**：本文是 ESP32-S3 双节点真机实测的完整报告，记录了三项核心实验（活动检测/呼吸憋气对照/呼吸定量验证），是 README 中"硬件实测数据"一节的原始依据。
> **代码对应**：感知层能力阈值 `waveguard/edge/config.py`（STILL_MAX/ACTIVE_MIN/SPIKE_MIN + BR_RATE_*），模拟轨剧本 `waveguard/replay/scenarios/` 基于实测信号特征构建。
>
> 测试日期：2026-07-31
> 结论先行：**活动检测信噪比 12.2:1，无接触呼吸检测误差 0.2 次/分，两项核心感知能力在 50 元级硬件上全部验证成功。**

---

## 一、测试目标

| # | 目标 | 对应系统能力 | 判定标准 |
|---|------|------------|---------|
| 1 | 验证 TX→RX 的 CSI 数据链路端到端打通 | 感知层基础设施 | RX 串口稳定输出 CSI_DATA 数据流 |
| 2 | 验证人体活动引起的 CSI 扰动可被检测 | 活动检测 / 跌倒检测基础 | 运动时扰动强度 ≥ 静止基线的 3 倍 |
| 3 | 验证无接触呼吸检测可行性 | "有呼吸静止 / 无呼吸静止"分级告警 | 频谱中出现与真实呼吸率一致的周期峰，且憋气对照下消失 |

---

## 二、测试环境

### 2.1 硬件

| 设备 | 规格 | 角色 |
|------|------|------|
| ESP32-S3 开发板 ×1 | N16R8（16MB Flash + 8MB PSRAM） | TX 发射器（COM5） |
| ESP32-S3 开发板 ×1 | 同上 | RX 接收器（COM6） |

硬件总成本约 **50 元**（两块 ESP32-S3 N16R8）。两板均经 esptool 烧录日志验明 8MB Embedded PSRAM，为真 N16R8。

### 2.2 软件

| 项目 | 版本/配置 |
|------|----------|
| 固件框架 | ESP-IDF v5.5.5 |
| 固件例程 | esp-csi `examples/get-started` 的 csi_send / csi_recv |
| 发射协议 | ESP-NOW 广播，信道 11，HT40，发包率 100 包/秒 |
| 增益控制 | espressif/esp_csi_gain_ctrl 0.1.5（自动增益补偿） |
| 串口 | CH343，921600 baud；实收帧率约 71~73 帧/秒 |
| 分析 | Python 3.14 + numpy/matplotlib，幅度=√(I²+Q²)，192 个子载波 |

### 2.3 场地

- 室内房间，门窗关闭，无风扇/空调气流，无微波炉工作，单人在场，无宠物
- 两板间距 1~3 米；呼吸实验时受试者坐于两板连线中间，胸腔正对连线

---

## 三、三实验结果汇总

| 实验 | 方法 | 关键结果 | 判定 |
|------|------|---------|------|
| 一：活动检测 | 静止→挥手/走动→静止 三段式 | 动/静信噪比 **12.2:1**（标准 3:1） | ✅ 通过 |
| 二：呼吸憋气对照 | 呼吸 30s→憋气 15s→呼吸 30s | 呼吸时子载波锁频共识，憋气时共识**瓦解** | ✅ 通过 |
| 三：呼吸定量验证 | 受控节奏 12 次/分呼吸 100s | 实测 **12.2 次/分**，误差 0.2 | ✅ 通过 |
