## 阅读建议

**想快速理解项目**：先读 [07-项目总览](07-项目总览.md) → 再读根目录 [README](../README.md)

**想理解技术架构**：[01-架构评审](01-架构评审.md)（为什么）→ [02-状态机设计](02-状态机设计.md)（怎么设计）→ `waveguard/edge/state_machine.py`（怎么实现）

**想验证医学准确性**：[03-医学研究](03-医学研究.md)（12 信源交叉验证）

**想复现硬件实验**：[05-硬件测试报告](05-硬件测试报告.md)（完整环境与方法）

## 关于命名

项目早期代号为"银发守望 WaveGuard"，现已统一为"**护院鹅 BreathGuard**"。文档中两名称指同一项目，部分早期文档保留原名以保留历史记录。
