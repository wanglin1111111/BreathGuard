> **文档说明**：本文是项目最初的定位文档，记录了参赛背景、专利口径、评审亮点设计和价值评估框架。

> **架构说明**：本文 §2.2 的"核心闭环"为早期叙述（语音确认门控），后经架构评审（见 `01-架构评审.md`）修正为"感知驱动并行决策"——以最新叙述为准。

## 一、一句话定位

**不用摄像头，也能守护独居老人。**
基于「射频信道感知」发明专利做感知层，基于 Qwen 大模型做认知层，为独居老人提供覆盖卧室、卫生间等隐私盲区的全屋无感守护。

---

## 二、痛点与方案

### 2.1 我们要解决的真问题

| 痛点 | 现有方案的缺陷 |
|---|---|
| 跌倒高发区在卧室和卫生间 | 摄像头因隐私原因无法进入，恰好覆盖不了最危险的地方 |
| 老人抗拒"被监视" | 摄像头方案心理接受度低，常被老人主动关掉 |
| 穿戴设备依赖老人配合 | 忘戴、忘充电、洗澡摘下——恰恰在最需要时失效 |
| 子女"报警疲劳" | 传统传感器误报多，告警泛滥导致真告警被忽略 |
| 出事后才知道 | 缺乏活动趋势分析，健康滑坡无法提前发现 |

### 2.2 我们的方案（经架构评审修正后）

```
感知层（专利技术）              认知层（Qwen 大模型）
─────────────────              ─────────────────────
Wi-Fi CSI 无感探测       →      呼吸模式分类（五级）+ 呼吸驱动决策
不采集任何光学图像       →      语音确证（仅辅助降级，Zone 2）
覆盖全屋含隐私区域       →      分级告警决策（消警/提醒/紧急）
无需穿戴、无需配合       →      病历个性化（8 种病史 + 开放式注册）
```

> ⚠ 本节为修正版叙述。原文档将"语音确认"作为核心闭环，经架构评审和医学 OSINT 研究验证后，已修正为"呼吸感知驱动决策，语音确认降为辅助"。详见 `01-架构评审.md` 和 `03-医学研究.md`。

## 三、评审亮点

1. **专利背书**：核心感知调度方法已提交国家发明专利申请并进入实质审查
2. **非视觉隐私守护**：全程不采集光学图像，直击养老监护最大伦理争议
3. **感知×认知架构创新**：呼吸感知驱动决策（非语音门控），CSI 呼吸检测实测误差 0.2 次/分
4. **Qwen 深度使用**：qwen-plus 做医学推理与分级决策，规则版降级保底
5. **病历个性化**：8 种病史自动调整检测与告警策略，开放式疾病注册
6. **技术演进兼容**：专利的能力等级探测机制（L1/L2/L3）保证未来更高精度感知硬件即插即升级

## 五、价值评估

### 5.1 社会价值

| 维度 | 说明 |
|---|---|
| 覆盖人群 | 中国 60 岁以上老人超 3.1 亿，其中空巢/独居老人规模约 1.2 亿 |
| 生命安全 | 跌倒是我国 65 岁以上老人伤害死亡首因；"跌倒后无人发现"是致死致残关键变量 |
| 隐私尊严 | 非视觉方案让守护不以牺牲尊严为代价 |
| 数字包容 | 老人端零操作、零学习成本 |

### 5.2 商业价值

| 路径 | 模式 | 说明 |
|---|---|---|
| C 端 | 硬件 + 订阅 | 硬件套装一次性收费 + 云端 AI 守护服务月订阅 |
| B 端 | 项目制 + SaaS | 养老机构、社区居家养老服务中心；按床位/户收年费 |
| G 端 | 政府采购 | "智慧养老""适老化改造"补贴目录，非视觉方案隐私合规优势显著 |
| 场景复用 | 同一专利架构 | 酒店防偷拍检测、仓储安防、无人值守空间管理 |
| 护城河 | 专利 + 数据 | 发明专利在审构成方法层壁垒；真实家庭 CSI 数据积累构成模型层壁垒 |

## 六、最终愿景

**让每一位独居老人都拥有一位看不见、不打扰、却始终在场的守护者。**

- 近期：跑通"L1 感知 + Qwen 认知"的最小守护闭环，验证核心假设
- 中期（1 年）：开源社区版沉淀真实场景数据，推出 C 端硬件套装
- 远期（3 年）：随 CSI 感知能力向 L2/L3 演进，成长为"非视觉家庭健康感知平台"
