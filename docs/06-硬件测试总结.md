## 二、最终总结

### 2.1 技术结论

1. **链路层**：ESP-NOW 100 包/秒发射 + 串口 921600 接收，实收约 72 帧/秒稳定无断流，端到端贯通
2. **活动检测**：动/静信噪比 12.2:1，为"剧烈波动后长时间静默 = 疑似跌倒"核心判据提供 **4 倍于标准的信噪比余量**
3. **呼吸检测**：
   - 定性——憋气对照下周期信号消失，"有呼吸的静止"与"无呼吸的静止"可区分
   - 定量——受控实验误差 0.2 次/分，测量精度达到可用水平
4. **方法论**：跨子载波频率一致性（锁频共识）+ 相邻子载波聚簇，两项实测发现直接反哺算法设计

### 2.2 工程与成本结论

- 全部能力基于 **约 50 元硬件**（两块 ESP32-S3 N16R8）+ 开源固件例程实现，无需任何专用传感器
- 从环境搭建到三实验完成仅用 1 个测试日，验证了技术路线的**低门槛可复现性**——这正是普惠养老赛道最需要的属性
- 每一步均有原始数据（3 份 CSV）、分析脚本方法、分析图可追溯复现

### 2.3 对项目的意义

- **专利支撑**：专利技术路线（Wi-Fi CSI 感知 + 认知层分级告警）的感知层核心假设全部获得实测支持
- **告警分级落地**：三实验合并后，分级告警逻辑首次具备完整实测依据——
  - 有活动 → 正常
  - 剧烈波动后长时间静默 + 仍检出呼吸 → 二级告警（疑似跌倒但存活体征）
  - 剧烈波动后长时间静默 + 呼吸信号消失 → 一级告警（最高级，立即处置）
