# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. Older snapshots are not maintained.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub Security Advisories:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, affected versions, and reproduction steps.

We aim to acknowledge reports within 7 days. Please allow time for a fix before public disclosure.

## Scope

- Credentials or secrets accidentally committed
- Command injection or unsafe file handling in scripts
- Dependency vulnerabilities with a practical exploit path
